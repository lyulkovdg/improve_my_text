# Цветовые параметры

Выбор расцветки осуществляется через палитру. В программе предусмотрено два активных цвета:

- **Основной цвет**: используется для рисования левой кнопкой мыши.
- **Фоновый цвет**: применяется для правой кнопки или работы стирательной резинки.

Вы можете изменять цвета по своему усмотрению, кликая на цветные квадраты. Если нужного оттенка нет, воспользуйтесь функцией «Изменение цветов», которая открывает расширенную палитру.
